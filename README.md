# Audioguys Music Tools

Audioguys Music의 사내 업무 도구와 파트너 서비스 바로가기입니다. 정적 파일을 기존 GitHub Pages 저장소 루트에 덮어쓰고 기존 assets/logos 폴더를 유지하세요.

app.js의 resources에서 항목을 관리합니다. name은 공식 앱명, label은 허브 표시명, glyph는 Hugeicons 이름, pinned는 자주 쓰는 도구 포함 여부입니다. aliases에서 검색 별칭을 관리합니다. 고정 항목은 배열 순서대로 최대 네 개까지 표시됩니다.

검색어는 공백·하이픈으로 나뉘며 선택한 범위 안에서 모든 단어가 일치해야 합니다. / 키는 검색창으로 이동하고 Esc는 검색어를 지웁니다. 카탈로그 포털은 별도 창으로 열며 팝업 차단 시 일반 링크를 사용합니다.

Pretendard 및 Hugeicons 데이터는 기존 jsDelivr 호스트에서 불러옵니다. 네트워크 차단 시 시스템 폰트와 텍스트로 도구를 실행할 수 있습니다.
